# AIMB-G1 correlated capture — historical v0.4 plan

Goal at the time: identify the event/command that makes the glasses enter Wi-Fi media-transfer mode.

This plan is preserved as history. It is **not** the current first-test workflow. Discovery v0.1 now performs the first physical check directly on the phone without Developer Options.

The original v0.4 plan used:
- an offline transfer gate,
- Bluetooth HCI logging,
- a network capture,
- one disposable test photo,
- timestamp correlation between BLE and network activity,
- a second repeat session for confirmation.

No personal or site/client media was intended for these experiments.
